# 威远镖局

单文件 HTML5 模拟经营。带 3D 角色、回合制战斗、20 关通关模式的武侠经营游戏。

直接打开 `index.html` 即可玩，也可装 `biaoju-app-release.apk`（安卓）。

---

## 怎么玩

开局 1 把随机一阶武器、320 两银、空库房。在三种运镖单里选一张，派遣镖师出镖，路上可能遇劫匪打一场回合制战斗，到达后结算银两与声望。声望到了升镖局等级，镖局等级到一定门槛才能解锁更稀有的运镖单和装备。

核心循环：**选镖单 → 派镖师 → 路上遇敌/支线 → 结算收益 → 升级/买装备 → 接更难的镖单**。

## 五种模式

| 模式 | 目标 | 失败条件 |
|---|---|---|
| 🏆 正常 | 攒够目标声望 | 无 |
| 💀 生存 | 银两/镖师用完前尽量多走镖 | 银两耗尽或镖师全灭 |
| ⚡ 竞速 | 50 天到 100 声望 | 超时 |
| ♾️ 无尽 | 走镖数尽可能多 | 银两耗尽或镖师全灭 |
| 🗺️ 通关 | 20 关逐关推进 | — |

### 通关模式（重点）

20 关递进，每关需同时满足三项条件才过关：
- **🚚 走镖趟数**：第 1 关 2 趟，逐关递增到第 20 关 16 趟，全程 175 趟
- **🏆 声望门槛**：第 1 关 12，逐关 +26，到第 20 关 506
- **🏯 镖局等级**：第 5 关起 2 级，第 17 关起 5 级（**不自动升**，需花钱升级）

每关过完会放烟花、弹通关公告（含奖励 + 下一关目标），最后进游戏时长 20 小时左右。

## 战斗

回合制，普攻/绝技/暗器三种操作。敌人机制：
- **护甲**：固定减伤
- **狂暴**：残血（<30% 血）触发，攻+30%
- **疗伤**：有冷却，吞药回血
- **破防**：重击可使玩家两回合防御减半
- **连招**：敌人有概率连击

玩家机制：怒气攒满可放绝技，暗器消耗品可投掷。

## 装备

- **武器 31 件**：刀/剑/枪/棍/暗器/拳掌六类，1-8 阶，1-5 星
- **防具 17 件**：护甲 7 / 战靴 5 / 头盔 5
- 库房开局只有 1 把随机一阶武器，防具清零，全靠购置
- 高阶装备需镖局等级 + 银两双门槛才能解锁
- 多余装备 50% 回收

## 操作

- **桌面**：鼠标点击按钮
- **手机**：触屏点击，竖屏最佳
- **库房/门派/弟子/分舵/秘籍/花名册**：底部按钮面板
- **委托书**：悬停（桌面）/ 长按（手机）查看详情

## 安装

### 安卓
1. 卸载旧版
2. 安装 `biaoju-app-release.apk`
3. 竖屏运行

### 浏览器
直接双击 `index.html`，或起一个静态服务器（如 `python -m http.server 8123`）后访问 `http://127.0.0.1:8123/`。

## 移动端特性

- 底部按钮组高度动态测量，驱动卡片区下边距，避免遮挡
- 通关模式任务条底部位置动态测量，驱动卡片区上边距
- 库房弹窗 tabs 二级 subtabs 视觉吸顶 + 阴影强化
- 战斗 UI 底部安全区适配（避手势条）
- 顶部安全区（刘海/水滴屏）适配

## 技术栈

- **单文件 HTML5**，无构建步骤
- **Three.js r128** 渲染 3D 镖师、劫匪、装备预览
- **Canvas2D** 渲染 UI、战斗特效、烟花、背景
- **WebAudio** 合成战斗音效
- **Capacitor 5 + Android Gradle** 打包 APK（v1+v2 签名）
- **localStorage** 存档（多槽位 + 自动存档 + 导出/导入救档）
